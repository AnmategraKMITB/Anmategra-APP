# Mengelola Rapor

Lembaga dapat membuat rapor untuk anggota lembaga maupun panitia kegiatan.
Rapor menggunakan profil ketercapaian yang dapat dipetakan ke profil KM ITB.

## Membuka halaman rapor

- Untuk rapor anggota lembaga, buka **Anggota** lalu klik **Rapor Komunal**.
- Untuk rapor panitia kegiatan, buka **Kegiatan**, pilih **Panitia**, lalu klik
  **Rapor Komunal** atau **Lihat** pada kolom rapor.

Judul halaman akan menunjukkan **Rapor Anggota** atau **Rapor Panitia** sesuai
konteks yang dipilih.

## Membuat profil penilaian

1. Pada halaman rapor, klik **Tambah Profil Kegiatan** atau
   **Tambah Profil Lembaga**.
2. Isi nama pada kolom **Profil**.
3. Isi **Deskripsi Profil**.
4. Pada bagian **Pemetaan dengan Profil KM ITB**, pilih profil KM ITB yang
   sesuai.
5. Klik tombol **+** jika satu profil perlu dipetakan ke lebih dari satu profil
   KM ITB.
6. Klik **Simpan Perubahan** untuk menyimpan profil.

Profil penilaian menjadi kolom pada tabel nilai. Buat profil sebelum mengisi nilai
agar penilaian memiliki konteks yang jelas.

## Mengubah atau menghapus profil

- Gunakan menu tindakan pada judul kolom profil untuk mengubah profil dan
  pemetaannya.
- Pilih opsi hapus pada profil yang tidak lagi digunakan, lalu konfirmasi.

Periksa kembali nilai yang sudah menggunakan profil sebelum menghapusnya.

## Mengisi nilai

Nilai berada pada rentang **0–100**.

1. Gunakan pencarian untuk menemukan anggota atau panitia.
2. Klik **Edit Nilai** pada tabel.
3. Isi nilai pada kolom profil yang sesuai. Anda dapat mengubah satu atau
   beberapa baris; setiap nilai harus berada pada rentang 0–100.
4. Klik **Simpan Nilai** untuk menyimpan perubahan.

Halaman **Rapor Komunal** adalah halaman tabel untuk mengelola nilai anggota
pada konteks lembaga atau kegiatan. Untuk menilai satu orang, cari namanya dan
ubah nilai pada baris tersebut tanpa mengubah baris lain.

## Mengimpor dan mengekspor nilai

- Klik **Unggah Excel** untuk mengimpor nilai dari file `.xlsx` atau `.xls`.
  Pada dialog **Upload Excel Rapor**, pilih file yang mengikuti format data
  rapor yang diterima aplikasi, lalu konfirmasi unggahan.
- Klik **Unduh** untuk mengekspor nilai seluruh anggota atau panitia ke file
  Excel.

Jika impor gagal, periksa jenis file, kolom, identitas anggota, dan pesan error
yang ditampilkan. Format template dapat berubah; gunakan petunjuk yang tersedia
pada versi aplikasi yang sedang dipakai.

## Membuka rapor untuk publik

1. Pada halaman **Rapor Anggota** atau **Rapor Panitia**, temukan toggle
   **Rapor Visible to Public**.
2. Aktifkan toggle jika rapor boleh terlihat dari profil mahasiswa.
3. Matikan kembali toggle untuk menyembunyikannya.

Visibilitas lembaga atau kegiatan biasanya nonaktif sampai lembaga membukanya.
Mahasiswa juga memiliki pengaturan visibilitas pribadi. Kedua pengaturan ini
dijelaskan pada [Melihat rapor mahasiswa](/manual/mahasiswa/rapor).

> [!WARNING]
> Nilai rapor dapat dilihat oleh pengguna lain setelah akses publik dibuka dan
> pengaturan pribadi mahasiswa mengizinkannya. Pastikan data sudah diperiksa
> sebelum mengaktifkan visibilitas.
