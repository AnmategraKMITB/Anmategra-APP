# Seeding data

- `*.csv` (generated by `generate_csv.py`) — **dev-only** Faker fixtures used by `npm run db:seed`. Never run against production.
- `lembaga-official.csv` — **real institution accounts**, maintained by the Anmategra team. Used by `npm run db:seed-lembaga`.

## `lembaga-official.csv` format

| column | required | notes |
|---|---|---|
| `email` | yes | official lembaga Google account email; must end `@km.itb.ac.id` or be added to `verified_users` (the seed does the latter automatically) |
| `name` | yes | lembaga display name |
| `description` | no | free text |
| `founding_date` | yes | ISO date, e.g. `2020-01-01` |
| `ending_date` | no | ISO date |
| `type` | no | one of `Himpunan`, `UKM`, `Kepanitiaan` |
| `major` / `field` | no | free text |
| `member_count` | no | integer |

The seed script generates `users.id` / `lembaga.id` itself — do not add ID columns. Re-running is safe (idempotent).
